# RIFT LAB

LoL 상대 챔피언 스킬 도감과 주간 전적 분석을 위한 개인용 웹 대시보드입니다.

## 실행 방법

- Node.js 18 이상이 필요합니다.
- 의존성 설치 없이 실행할 수 있습니다.

```bash
node server.js
```

또는 `npm.cmd start`로 실행할 수 있습니다.

브라우저에서 `http://localhost:3000`을 열어 주세요. Riot API 키가 없으면 화면은 명확한 표시가 있는 샘플 데이터 모드로 동작합니다.

## 실제 Riot 전적 연결

1. `.env.example`을 복사해 프로젝트 루트에 `.env` 파일을 만듭니다.
2. Riot Developer Portal에서 발급한 키를 `RIOT_API_KEY`에 설정합니다.

```dotenv
RIOT_API_KEY=RGAPI-발급받은키
PORT=3000
```

3. 서버를 재시작하고 브라우저에서 Riot ID를 `게임이름#태그라인` 형식으로 추가합니다.

API 키는 서버에서만 사용하며 브라우저에 전송하지 않습니다. 개발자 키는 만료되거나 호출 제한이 있을 수 있으므로 Riot의 API 정책과 키 상태를 확인해 주세요. KR·JP1 계정은 아시아 라우팅을 사용합니다.

## 주요 기능

- 최신 Data Dragon 한국어 챔피언 검색 및 패시브/Q/W/E/R 스킬 정보
- CommunityDragon 최신 한국어 게임 데이터 기반 패시브 조건·수치·쿨다운 상세
- Riot ID 최대 10개 등록 및 계정별·통합 주간 전적 조회
- 한국 시간 월요일 00:00 기준 통계 기간
- 솔로/듀오 랭크, 자유 랭크, 일반 게임 필터
- KDA, 평균 CS, 경기 시간 및 챔피언별 승률
- Riot ID와 필터만 브라우저에 저장. 통계 기록은 주간 아카이브하지 않음

스킬 피해 유형 보강 데이터가 없는 경우 임의로 추정하지 않고 `미확인`으로 표시합니다. 패시브 수치 상세는 스킬 도감을 처음 열 때 CommunityDragon에서 불러옵니다. Riot API 호출 제한에 도달하면 일부 결과가 누락될 수 있으며, 안내 후 다시 조회할 수 있습니다.
